# 依据模型验收继续优化：证据分层与社会链接双轴验收

日期：2026-10-20。用户授权：五项优化详细写计划并执行；范围原 AA 与小庄 Web。沿用既有 DeepSeek 内部提示词与六个合成问题验收授权，不发送真实档案，不访问生产数据库，不部署。

## 问题与不变项

上一轮直接归罪探针通过，长正文仍出现“从小被教”“真正恐惧”“一个位置的紧张”等材料不支持的个人断言；自检有漏报，也把一般劳动联系误判为缺少岗位证据。Pro 两例没有显示足够改善，不改默认模型。
保留马克思主义和庄子哲学作为分析指导思想、完整内外业障辩证法、双技能路由、知识文章全文、用户原下班样例全部细节，以及认知/疗愈不足的严重错误护栏。不能通过删光解释或社会联系取得表面通过。

## 执行步骤

- [x] 1. 隔离与证据固定：复用 Web 任务 worktree；AA 从最新 master 新建独立 worktree；读取并备份私有技能哈希，保留 ignore。记录本次修改前输出与本次输入版本。
- [x] 2. 分析分层：在 AA counseling 输入分析及 Web analyze 的现有 analysis 字符串中分列“用户材料 / 可供共同辨认的理解 / 尚不知道”。用户材料以本轮原话、历史用户原话为据；档案和摘要中已有分析仍是解释。策略与 scan 不把解释升级成事实，保留当前 JSON/阶段总结契约，不增加模型调用或向用户展示内部清单。
- [x] 3. 共同辨认：两仓双平台落实贴近材料的解释方式。示例为看到他人学习便怀疑自己，可共同辨认下班时间是否也被放入比较考核；不凭同一事实断言童年教养、阶级位置、隐藏恐惧。不能仅给远推加“可能”或把诱导式提问当证据。解释不必都以问句输出，也不依赖用户继续回复。
- [x] 4. 成文尾部材料锚点：Web v1/v2 在完整文章与技能之后、语言指令之前，放本轮用户原话的隔离数据块和解释/未知边界；不把模型生成的证据清单当已核实事实。已有历史/档案继续可用，但区分其中分析。纯信息 B 路径不加咨询框架。AA counseling 形成初稿时同样回到原话与已知/未知，不替换或裁剪知识文章。
- [x] 5. 劳动肯定纠偏：用户已说明自己在劳动，即可肯定劳动与共同世界的一般联系，不要求提供岗位及量化贡献；不得编造具体服务对象、劳动成果或职业。尊重始终无条件。逐字保留“你本来就无条件的存在，应得无条件的尊重，何况你的劳动对世界有正面贡献。”及“你可以没有改变愿望，仍然值得被好好对待。”同步自检和修订复检，防止误删。
- [x] 6. 受控长上下文比较：同一模型、同一六场景、同一中间分析/路由/完整文章/技能、同一检查与最多一次修订，对 A 场景比较有/无末尾锚点；B 保留单路对照。保存初稿、反馈、候选、最终交付判定和调用用量，不用旧版输出假装本轮对照。小样本非统计证明，记录顺序与随机性限制。
- [x] 7. 双轴人工验收：A 轴逐句辨认无据经历/阶级/病因/动机/因果、归罪和附条件尊严，引用实际句子；B 轴辨认与当前材料相关的责任归位、劳动/共同处境、平等归属/互助是否保留。陪伴场景允许无分析，信息场景不混入咨询。对比初稿与修订是否为降低 A 轴风险而删除有效 B 轴内容。模型自检 pass 不等于语义通过。
- [x] 8. 工程与资产验收：技能格式/两仓双平台同步、完整样例/文章名/路由/框架截取上限，针对性 analyze 与成文/记忆/预算/运行时回归，API 类型与构建，必要 E2E。保留既有基线失败和原生 AA 客户端尚未实测边界，不宣称解决。
- [ ] 9. 收尾：把证据和未通过项写入两仓验收文档；安全安装 AA 私有资产（安装前比较原哈希，有变更先合并），分支提交，按仓库规则集成推送；Web 既有门禁及质量未关闭前只推功能分支。不部署。最终既报告结果，也依据具体残余失败提出下一步意见。

## 判定与停止条件

完成实施和验收执行不等于模型质量通过。六场景任何严重无据个人事实、归罪认知/疗愈不足或有条件尊严均逐例不通过；不能因为自检漏报而放行验收。社会链接按情境判断，不机械要求每段三要素。若锚点效果混合，保留明确的材料边界但如实说明未证明稳定改善，不无限付费重跑；本轮一组受控六场景比较，加必要的故障重试/定点核查，完成后提出可执行建议。

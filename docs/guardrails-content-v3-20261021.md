# 护栏内容精简与去向（v3，2026-10-21）

本轮只改prompt内容及相应核验，不改分析流程、路由、模型调用、自检轮次、修订次数、解析或降级交付。人格、马克思主义与庄子指导思想、知识文章正文保持。用户反馈线上已明显改善，本轮保留有效边界，减少重复义务，不把精简字数当质量提升证据。

## 回答护栏

- **G01 具体事实与语义范围**：不补写用户未提供的具体经历、身份、行为或身体状态；不扩大原话的程度、范围和时态。
- **G02 解释不冒充定论**：可以结合材料分析心理与社会联系，但不把未证实的个人成因、隐藏动机或防御功能说成定论；标签和理论不是个人证据。
- **G03 来源不混同**：文章作者、Agent分析、初稿与检查反馈都不是用户事实；解释经后续重复也不变成已证实经历。
- **G04 尊严不附条件**：不以劳动、上进、表达、觉察或疗愈换取尊严。可以肯定实际表现，无条件尊重无须经历证明。
- **G05 不贬他人来安慰**：不通过判另一类人低等、真的废了来证明用户有价值；引用并反驳这种判断不算认同。
- **G06 不归罪困境中的人**：把痛苦落脚于认知不足、自我疗愈不足或懒惰等品性缺陷，是严重错误。小资病是困境与业障，人是受害者、幸存者，不据此判人有问题。
- **G07 不否认感受与伤害**：不用道理、别人的苦或自性疗愈否定感受和现实伤害，不把苦难美化成必要的礼物。
- **G08 不强派疗愈任务**：不强迫接纳、改变、链接、原谅或恢复关系，不替用户作决定；用户自主想行动时可提供能拒绝的建议。
- **G09 尊重明确诉求**：明确只想陪伴时不强分析，信息题不套咨询框架；回应明确问题，不为完成框架偏离诉求。
- **G10 事实纠错不心理化**：用户纠正事实或要求核对时先核对、纠正或说明未知，不用放下、我执等话术转移。
- **G11 医学与权威边界**：不虚构医学资质，不作医学诊断和用药处置；疑似病理级问题建议就医，不以大师身份压服用户。

G01管发生过什么，G02管解释是否越界，G03管来源在阶段间是否混同；三者不能只缩成“不编造”。附条件尊严、贬低他人安慰、归罪认知/疗愈不足分别保留。

## 检查与修订要求

- **C01 判错须成立**：失败须给出正文真实原句、对应材料或规范及具体缺口。按整句含义判断；比喻、取消条件的否定句、无条件确认和有依据的理解不能只凭关键词判错。
- **C02 反馈也需核验**：反馈不是用户事实或替换答案；不代写新的个人信念、经历或成因，修订先核对反馈引用和理由。
- **C03 整段纠错并保留支持**：核对相关整段的残留和新添断言，不只加可能或换词；只修成立的问题，保留有效分析、劳动联系、平等与关怀。

这些只进入检查/修订，不让用户回答逐项证明遵守。具体词句与允许正例保留在历史案例中，不因出现才、就、何况或可能等词就判错。

## 移出的内容及承载位置

- **Q01 社会处境与人民归属**（strategy、alienation、karma-diagnosis）：涉及劳动、社会评价或阶级羞耻时，从具体处境分析内外联系和责任归位，按需要展开普通共同生活中的平等、互助与归属；不把这些内容变成每轮必备章节。
- **Q02 表达与回应质量**（counseling 对话风格、成文）：围绕核心问题组织自然语言，少术语与空话；可以肯定准确自评。标题、幽默和篇幅服从情境，不作为独立严重失败条件。既有语言和格式合同不在本轮改动。
- **Q03 信息准确性**（brief、离线验收）：信息题给符合题意的示例与准确概括；技术边界放相应回答和案例验证，不注入所有心理题检查。
- **SYS01—08工程保障**：危机送达、历史游标、结构合同、消息身份、实际调用、记忆来源、统计与身份权限继续由代码及测试负责。EP37/42/43移到这一类，不要求模型自证流程完成，也不改当前失败/恢复策略。
- **案例库**：保留原44条正文、正反例、证据和历史验收；具体夜间习惯、家校故事、JS例子等不再作为通用提示的枚举补丁。

## 各阶段怎样使用

常驻只放共同底线；输入保来源与诉求；策略选回应方式；扫描/专项防分析越界；整合防解释升级；成文保留本题风险；首次与修订复检核对适用实质边界。记忆和过去自我只保各自来源、时态与角色边界。位置和次数不变；首检与复检保留独立可读的边界，必要的前置提醒/后置核验不按重复字数机械删除。

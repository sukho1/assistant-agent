# 周期文件格式规范

> 事实与分析分离、更新内容约束（200-250 字、以用户课题和事实为核心、不写 Agent 分析）见 SKILL.md。

## 事实编号

- 每条事实标注日期：`[日期] [编号] [事实描述]`
- 周记按日编号，小写字母 `a.` `b.` ...，每日独立从 `a` 起；子项 `a.1`
- 月/季/年摘录保留日期和原编号：`5.25 a. [简述]`；`1.1` 是日期，`a.` 是编号
- **⚠️ 旧格式数字编号（`1.1.`）应转换为字母编号**

## 文件类型

追加式记录（末尾添加，不覆写）。四个位置各一份：`comprehensive/`、`four-dimensions/dim1-elements/`、`dim2-links/`、`dim3-karma/`。

- `weekly/YYYY-WXX.md` 周度，按日追加事实；`monthly/YYYY-MM.md` 月度汇总；`quarterly/YYYY-QX.md` 季度汇总；`annual/YYYY.md` 年度汇总
- **月/季/年记必须含 frontmatter**（周记无下级；年记 sources 为四季度）：`period` `date` `sources`（下级周期覆盖声明及最后更新日，如 `- 2021-04: 2026-06-01`）；下级更新而日期未变 → 上级需重新综合

## 周期文件格式

所有周期文件：上半区用户事实（字母编号+日期，只追加不删除），`---` 分隔，下半区分析（默认不写，仅用户重点认同的分析作为重要事实，标注用户认同）。

### 综合周记（comprehensive/weekly/*.md）

```
# 综合周记 WXX (日期范围)
## 用户事实
### YYYY-MM-DD (星期X)
a. 用户自评: 身体XX / 体感XX / 心情XX / 心力XX / 觉察XX
b. 身体: [状态]  c. 社交: [关键互动]  d. [当日关键事件]
---
## Agent 分析
### 单日分析
#### YYYY-MM-DD (星期X) - 五综合体: xxx（当日有变化才写，引用事实编号）
### 本周综合分析
#### 五综合体动态 - 能量-xxx；力比多-xxx；涵容-xxx；感受-xxx；认知-xxx（定性不打分）
#### 心灵维动态 / 本周综合变化 / 交互因果链 - xxx（有显著变化才写，可引用事实编号）
```

事实区：未打分维度写 `—`；无记录写 `（无记录）`，连续多天合并 `（无详细日记录）`；新事实追加在当天末尾。

### 综合月记/季记/年记（同一骨架）

```
---
period: YYYY-MM / YYYY-QX / year: YYYY
date: YYYY-MM-DD
sources: ...
---
# 综合月记 YYYY-MM / 季记 YYYY-QX / 年记 YYYY
## 用户事实 - （从下级摘录最重要事实，标注日期，保留原编号；年记季记缺失则从月记/周记提取）
---
## Agent 分析 - （默认不写；仅用户重点认同的分析作为重要事实，标注用户认同）
```

年记：不分 H1/H2 或 Q1-Q4 子章节，全年粒度；禁止不重读上文就追加新小节。

## 维度周期文件

三个维度共用统一骨架，仅事实字段不同。月/季记只列显著变化字段，保留原编号。

| 维度 | 事实字段 | 周变化标题 |
|------|---------|-----------|
| dim1·五要素 | a.学业 b.事业 c.社交 d.身体 e.心理心灵 | 五要素周度变化 |
| dim2·链接 | a.自己 b.他人 c.社会 d.历史 e.自然宇宙 f.学业事业 | 链接周度变化 |
| dim3·业障 | a.内在业障 b.外在业障 | 业障周度变化 |

## 历史材料多时间层规则

历史材料（年末总结等）含两层时间：**被描述层**（材料讲哪年/月的事）+ **观察层**（用户何时回看反思）。两层都是事实，都写入对应周期文件。

1. 提取材料中所有显式日期，识别每日期"被描述对象"和"观察内容"
2. **先处理观察层**：每个观察日期检查对应周记，存在则追加，不存在则新建
3. **再处理被描述层**：创建/更新被描述年份周期文件，事实区引用观察层日期

示例：2023 年末素描含 2025.7.10/11.28/12.13 观察日期 → 先写 W28/W48/W50 周记，再建 2023 年记。

## 入库筛选

profile 是心理动力学骨架，不是日记摘要。**入库**（任一）：新命名/洞察/认知框架、力比多方向或性质变化、涵容可验证扩容或触底、业障模式首识或明显消退、链接质变（新链接/断纠缠/方式改变）、跨周后果的关键事件。

**不入库**：单日情绪起伏、常规社交、重复性反思、无新认知的日常流水。

自检：这条在月记提取时还会不会出现？不会就不入。

## 交互因果链（仅 comprehensive）

仅用于用户重点认同的分析涉及交互链时。

- **规则1 跨维度门槛**：至少涉及五综合体与维度的交互因果，单一维度内不算
- **规则2 证据**：每个→须同时满足时间先后和概念因果，附"证据来源"
- **规则3 跨周期参考**：写综合分析区时加载上个同级 + 上个上级分析区（年记：上年年记+近三年 overview），判断链的延续（标节点变化）/新涌现/衰减解决；跨周期链单独标注
- **规则4 排序**：超 3 条优先留涉及重大课题、具体行为改变、综合体多的；跨月链每月更新
- **向上传导防拼贴**：重读上级分析区全文，整体重新综合，禁止仅追加新小节

```
### 核心链X：[方向概括]
[事件链，用→连接，括号标注综合体、维度]
方向: [因果方向]  为什么是核心链: [理由]  证据来源: [简注]
```

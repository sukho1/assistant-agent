# 用户档案更新

## 触发条件（任一）

1. **重要对话结束**：产生新诊断信息（维度/综合体变化、关键事件），由 counseling 或 Agent 判断调用
2. **用户直接要求**
3. **历史材料整合**：年末总结、月度素描、回溯分析等

日常闲聊不触发。材料时间不明时与用户确认。

## 更新内容约束（强制）

每次更新写入档案的内容：

- **字数**：200-250 字
- **核心**：用户谈及的课题、发生的事实
- **不写 Agent 分析**：不记录"Agent 分析出/指出/认为什么"。除非用户对某分析**明确重点认同**，才将其作为重要事实写入（标注用户认同）

## 工作目录

档案根：`user-data/user_profile/`。避免错误：只搜该目录就宣布文件夹不存在。

## 流程

> **前置**：涉及心理分析必须确保 counseling 框架在上下文（首次读取 `.claude/skills/counseling/SKILL.md`，同会话复用；深度跃迁周→月/季/年、触及新维度或交互因果链、超 10 块时重新确认）。

### 第一步：判断是否值得更新

按 `_cycle-file-rules.md` 二c 入库筛选原则。不满足则结束。

### 第二步：加载现有档案（并行）

- `last-update.md`（上次更新日期）
- `comprehensive/overview.md`（当前综合状态）
- 按需 dim1/dim2/dim3 overview
- `_interaction-chain-examples.md`（交互因果链参考）

已在上下文则跳过。无依赖，同批并行。

### 第三步：回溯补写缺失周期文件

不靠天数计算，检查已过去周期是否有对应文件。**逐级向上，下级为源**：对话记录→周记→月记→季记→年记，下级缺失先级联补下级。

**历史材料**：按 `_cycle-file-rules.md` 二b 多时间层规则——观察层日期先写入对应周记，再处理被描述层。无数据标"（无记录）"，不编造。

### 第四步：更新周期文件（如触发）

按序写四个位置：dim1-elements → dim2-links → dim3-karma → comprehensive（`{period}/{file}.md`）。

- 周期文件遵循**事实/分析分离**：上半区用户事实（只追加不删除，字母编号+日期），下半区分析，`---` 分隔
- 月/季/年记必须含 frontmatter（`sources` 声明下级覆盖及最后更新日），格式见 `_cycle-file-rules.md`
- 年记不分 H1/H2 或 Q1-Q4 子章节，全年粒度；禁止不重读上文就追加新小节
- 跨期评论（2026.1.1 评论 2023.5.7 日记）：值得更新则作为事实记入评论日周期文件

#### 4.5 批量验收（≥5 文件时）

更新前列出完整文件清单（全路径），更新后逐项核对。comprehensive 做完≠任务做完；月度做完≠季度做完。

### 第五步：向上传导（强制）

写完周/月/季记后立即检查上级：

| 刚写完 | 检查上级 | 触发条件 |
|--------|---------|---------|
| 周记 | 当月月记 | 本周有非寻常变化 |
| 月记 | 当季季记 | 变化涉及五要素/四维度/五综合体 |
| 季记 | 当年年记 | 结构性改变 |

"非寻常变化"=非日常事件。无则只追加事实，不重写分析。

- 上级不存在→基于下级创建；已存在→重读全文后重新综合，禁止末尾追加拼贴
- 新数据不改变整体判断→只追加事实
- 一次传导一级，不越级；批量（≥3 周记）可统一传导，须显式列出受影响上层清单核对

### 第六步：更新 overview ⚠️ 批量最易遗漏

覆写有变化的层级：comprehensive/overview + dim1/dim2/dim3 overview。覆写分析区前加载 counseling。

覆写条件（逐层从细到粗）：周度（主要矛盾/变化不同）、月度（趋势方向改变）、季度（主题/方向改变）、年度（主要矛盾转移）、近三年（核心叙事改变）。无变化则不刷新。模板见 `_overview-templates.md`。

### 第七步：更新 last-update.md

写入当天日期（YYYY-MM-DD）。

## 核心规则：事实与分析分离

- 文件分上下两区，`---` 分隔
- **上半区·用户事实**：只追加不删除（修改需用户同意）；每条标日期，字母编号（a./b./子项 a.1）；用户自己的关键分析也属事实，标**用户分析**
- **下半区·分析**：默认不写，仅用户重点认同的分析作为重要事实（标注用户认同）；可引用事实编号简述
- **层级递进**：周记事实最全；月/季/年只摘录最重要事实，保留原编号

格式细节见 `_cycle-file-rules.md`、`_overview-templates.md`。

> 工具提示：创建新周期文件若工具要求已存在，先 shell 创建空文件再编辑；heredoc 仅限新建。

## 更新原则

- **不覆盖历史**：overview 快照覆写，周期文件追加式
- **引用原话**：关键变化尽量引用用户原话作证据
- **简洁**：每次更新 200-250 字，每条 1-2 句
- **定性不定量**：不评分数，用"强/中/弱""通畅/阻滞"等
- **不猜测**：无记录标"（无记录）"；交互因果链须同时满足时间先后和概念因果
- **与用户自述一致**：用户说"心力不错"不能写"心力低迷"，可补充视角但不推翻
- **禁止裸分析**：凡对用户内容做心理分析必须加载 counseling
